## Permission and honest use

The user supplied these assets and asked that they appear in the website. The original photographer, model, logo designer and licence terms have not been independently verified. Record the actual creator and permission in the group rules sheet; user supply alone is not proof of ownership. Do not describe the person in the hero picture as an actual employee or a named member of this business. No such identity or affiliation has been verified.

## Original vector drawings retained

The skirt and towel cards now use the supplied `skirts.jpg` and `towels.jpg` photographs. Original SVG illustrations are retained only as fallback assets. Earlier original SVG drawings, including `skirt.svg`, remain available as fallback assets. No external clip-art was copied into those SVG drawings.
